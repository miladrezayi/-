# Siren Radio | Android

نسخهٔ آغازین یک اپ مستقل اندروید برای سرگرمی و پخش افکت‌های بی‌سیم و آژیرهای امدادی.

## امکانات نسخه 1.0.0
- پنل فارسی با چیدمان راست‌به‌چپ و تم تیره
- کلید فشاری Push-to-Talk با صدای شروع، خش‌خش و پایان
- افکت‌های تولیدشده و اختصاصی: پلیس دو تُن، پلیس اروپایی، آتش‌نشانی، آمبولانس، بوق هشدار و بوق بم
- پخش هم‌زمان چند افکت و تنظیم بلندی هر افکت به‌صورت جداگانه
- اعلان دائمی هنگام پخش در پس‌زمینه و فرمان «توقف همه»
- کارکرد آفلاین، بدون اینترنت و بدون ارسال داده

## ساخت APK

1. پروژه را در Android Studio باز کن.
2. از نصب بودن JDK 17 و Android SDK Platform 35 مطمئن شو.
3. Gradle Sync را اجرا کن.
4. از مسیر Build > Build Bundle(s) / APK(s) > Build APK(s) خروجی بگیر.

همچنین Workflow داخل `.github/workflows/android.yml` با هر Push به شاخهٔ `main` یا `master` و با اجرای دستی، APK دیباگ را می‌سازد و به‌عنوان Artifact تحویل می‌دهد.

## فایل‌های صوتی

تمام فایل‌های WAV داخل `app/src/main/assets/sounds/` به‌صورت موج‌های صوتی مصنوعی برای این پروژه تولید شده‌اند؛ از نمونه‌برداری یا کپی صدای ضبط‌شدهٔ اشخاص، سازمان‌ها یا آژیرهای دارای حق نشر استفاده نشده است.

## نکتهٔ مهم

این برنامه صرفاً شبیه‌ساز افکت صوتی و سرگرمی است. قابلیت ارسال رادیویی، ارتباط با نیروهای امدادی، پخش پیام زنده از طریق شبکه یا فعال‌کردن چراغ هشدار خودرو ندارد. از صداها برای فریب، ایجاد مزاحمت یا القای وضعیت اضطراری واقعی استفاده نشود.

## مبنای فنی و مجوز

این نسخه یک پیاده‌سازی مستقل است. الگوی کلی soundboard و مدیریت پخش محلی با بررسی پروژهٔ [OMGSoundboard](https://github.com/OMGSoundboard/android-app) الهام گرفته شده، اما سورس آن در این پروژه کپی نشده است. کد این پروژه با مجوز MIT منتشر می‌شود؛ وابستگی‌های شخص ثالث تابع مجوزهای خود هستند.
